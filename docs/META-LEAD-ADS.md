## 8. Must confirm with Jarrod before launch

1. **Does the $250 come off the $2,450**, or is $2,450 already the discounted price? The badge reads as if both stack.
2. **Response time** for the call back.
3. **Jobs per week.** If he can't give a real number, delete the scarcity line. Don't invent one.
4. **Offer end date.** If there's no real deadline, change the P.S. to drop it.
5. **Free flake sample.** Does he actually hand these out?
6. **Workmanship terms.** Nothing about warranty goes in until it's written down.
7. **Dollar value of the free measure and the sample**, so the stack can show them. If there's no honest number, drop the "(Worth …)" text from those lines.
8. **"On the tools himself."** Taken from the brief. The site's rule is never "no subcontractors", so the ads say he works on the jobs, not that he does every job alone.
9. **A real Google review quote** with the reviewer's first name and suburb.
10. **Phone originals** of the garage before/after.
